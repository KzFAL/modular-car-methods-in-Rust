## 📋 Как получить список методов на своём сервере | How to get the method list on your server

**RU:**  
Установите плагин **KZmycarMethods** на сервер, зайдите в игру и пропишите в чат команду `/mycar`.  
Все методы и поля ModularCar будут выведены в консоль сервера с префиксом `[car]`.

⚠️ **Важно:** После использования **рекомендуется немедленно удалить плагин** с продакшен-сервера, так как команда доступна всем игрокам и её могут спамить. Плагин предназначен только для одноразового получения списка API.

**EN:**  
Install the **KZmycarMethods** plugin on your server, join the game, and type `/mycar` in chat.  
All ModularCar methods and fields will be output to the server console with the `[car]` prefix.

⚠️ **Important:** After use, **it is highly recommended to delete the plugin immediately** from your production server, as the command is available to all players and can be spammed. The plugin is intended for one-time API list retrieval only.
